# Demo transcript of the chat agent (scripted model)

`transcript/001_plan.json` ... `011_layout.json` are the prompts the harness sent and the replies a *scripted* model (replaying
the hand-made example layout) returned: one plan turn, then one layout turn per subsystem. Open a file to see exactly what a
real model gets to read (`messages`) and what it must answer (`reply`: one JSON object). `run_summary.json` is the outcome.
